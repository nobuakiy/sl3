まずは **トークン定義** から始めます。
今回の小言語はCライクな構文にオブジェクト指向・関数型要素を混ぜ込む形なので、トークンはキーワード・識別子・リテラル・演算子などをしっかり切り分けておくとパーサーがシンプルになります。

---

## 1️⃣ トークン定義（Token Specification）

### 📌 キーワード（予約語）

```
int, char, StringBuffer, struct, module, bool,
if, else, while, return,
true, false,
append, clear, length,
=>    // ラムダ構文用
```

---

### 📌 記号（Symbols / Operators）

| カテゴリ | トークン | 説明 |
|----------|----------|------|
| 括弧 | `(` `)` `{` `}` `[` `]` | 関数呼び出しやブロック |
| 区切り | `,` `;` `.` | 引数区切り、文末、メンバアクセス |
| 演算子（算術） | `+` `-` `*` `/` `%` | 四則演算・剰余 |
| 演算子（代入） | `=` `+=` `-=` `*=` `/=` | 代入系 |
| 演算子（比較） | `==` `!=` `<` `>` `<=` `>=` | 比較 |
| 演算子（論理） | `&&` `||` `!` | 論理演算 |
| 特殊 | `=>` | ラムダ定義 |

---

### 📌 リテラル（Literals）

- **整数リテラル**
  - 10進: `123`
  - 16進: `0x1A`
- **文字リテラル**
  - `'A'` → `65` (ASCIIコード)
- **文字列リテラル**
  - `"Hello World"`（固定文字列）
- **boolリテラル**
  - `true` / `false`

---

### 📌 識別子（Identifiers）

- 英字または `_` で開始し、英数字と `_` を含められる
- 例: `myVar`, `_temp1`, `Point`

---

このトークン定義をもとに、次は **BNF構文定義（2️⃣構文ルール）** に進めます。
BNFを作れば、後でPythonでの字句解析・構文解析に直接流用できます。

このままBNFルールに進みますか？それとも、トークン定義の段階で演算子優先順位や字句解析の正規表現例も追加しておきますか？
