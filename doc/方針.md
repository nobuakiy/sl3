8bit CPU用のミニ言語のコンパイラをpythonで作成する。
- Z80を当面のターゲットとするが、6809などにも追加で対応予定
- asez80で読み込み可能なアセンブラソースを出力する
- C言語を簡略化したような文法
- ヘッダーとマクロはない
- 他のモジュールの参照は、import で、pythonのように参照が可能
- マクロはないが、定数宣言はある。大文字にしなければならない。
- 基本的な型として、16bit のintと、8bitのbyteがあり、byteは符号なしで0-255の範囲の値を扱う。
- "abc"などと書くと、文字列定数となり、変更はできない。
- 文字列で編集したい場合には、StringBufferという型を使う。
- StringBufferは、初期化時に最大長を指定する。
- 通常の加減乗除のほかに、論理演算がある。シフトもあるが、論理シフトのみで算術シフトは行わない。
- += -= などはあるが、++ -- は実装しない。
- 一次元の配列がある。
- 通常は宣言時に最大長を指定する。
- 配列定数があり、次のように指定して初期化したものは、配列の定数宣言となり、最大長は省略可能だが、内容の変更はできない
    const ARRAY_A:[int] = [0,1,2,3] 
- bit位置を指定して、bitの参照、代入、トグルが可能。 a.3 = 1; のように書く
- 関数宣言が可能
- 最初の関数引数は、レジスタを使う
- 変数、関数のアドレスを取得可能
- メモリに対して、取得・設定が可能。 MEM[0x8000] = 0x21; のように書く
- 配列、文字列、StringBufferのそれぞれの要素に対して繰り返しを実施するのは、次のようなfor文が書ける
    for item in [0,1,2,3] do { print(item); }
